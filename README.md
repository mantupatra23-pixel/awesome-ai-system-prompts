## ⚙️️ How to Use & Benchmark

Every prompt in this repository adheres to the **Promptory Deterministic Framework**:

1. **Imperative Role Isolation**: Declares strict operational personas without meta-narrative fluff.
2. **Negative Constraints**: Strictly eliminates conversational preamble, filler apologies, and lazy code placeholders (`// TODO`).
3. **Dynamic Bracket Parameters**: Uses explicit runtime variable tokens (e.g., `[CODE_SNIPPET]`, `[PERFORMANCE_GOAL]`) for instant customization.

You can interactively test, fork, and synthesize dynamic variables in real-time on **[Promptory.xyz](https://www.promptory.xyz)**.
